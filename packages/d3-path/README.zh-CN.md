# d3-path

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation Canvas-to-SVG path string serializer (moveTo, lineTo, quadraticCurveTo, bezierCurveTo, rect, closePath) (clean-room MIT implementation of npm d3-path, #400 / 134M wk)

## 安装与导入

```bash
cap add d3-path
```

```cp
import { example } from "d3-path";
```
