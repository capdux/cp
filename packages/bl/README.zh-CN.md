# bl

> 版本：`6.1.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-heap segmented BufferList for streaming byte reads, big/little-endian integers, indexOf, and consume

## 安装与导入

```bash
cap add bl
```

```cp
import { newBufferList } from "bl";
```

## 核心导出 API

- `export fn newBufferList(): BufferList;`
