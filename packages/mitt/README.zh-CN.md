> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation tiny functional event emitter with wildcard '*' support in pure CP (npm mitt v3 parity)

## 安装与导入

```bash
cap add mitt
```

```cp
import { mitt } from "mitt";
```
