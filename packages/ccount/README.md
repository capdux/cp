# @cap/ccount

Zero-allocation character/substring occurrence counter and longest consecutive streak finder in pure CP (covers both `ccount` and `longest-streak`).

## API

- `ccountByte(value: string, ch: u8): usize`
- `ccount(value: string, needle: string): usize`
- `longestStreakByte(value: string, ch: u8): usize`
- `longestStreak(value: string, needle: string): usize`
