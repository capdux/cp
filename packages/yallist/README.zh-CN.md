# yallist

> 版本：`1.0.0` | 许可证：`ISC` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation O(1) doubly linked list backed by a fixed 64-slot freelist pool (npm yallist v5 parity) in pure CP

## 安装与导入

```bash
cap add yallist
```

```cp
import { example } from "yallist";
```
