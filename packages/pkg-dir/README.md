# `pkg-dir`

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`npm:pkg-dir` ([https://github.com/sindresorhus/pkg-dir](https://github.com/sindresorhus/pkg-dir))

Zero-heap package root directory finder locating the nearest ancestor `package.json` or `cap.json` — clean-room CP equivalent of npm `pkg-dir`.

Reuses `@cap/find-up` and `@cap/npm-run-path` as independent packages.
