# @web/jwt

> Official zero-heap HS256 JWT authentication plugin for `cap:web` (pure-CP SHA-256, HMAC-SHA256, Base64URL).

- **License**: MIT
- **Type declarations**: [`src/index.d.cp`](./src/index.d.cp)
- **Install / Import**:
  ```cp
  import { sha256, hmacSha256, base64UrlEncode } from "@web/jwt";
  ```

## Overview

`@web/jwt` provides zero-heap HS256 JSON Web Token signing and verification middleware for `cap:web`, powered by pure-CP SHA-256, HMAC-SHA256, and Base64URL primitives.

For full API signatures and examples, see [`src/index.d.cp`](./src/index.d.cp) or [`README_AGENT.md`](./README_AGENT.md).
