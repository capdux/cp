# postcss

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-heap CSS AST parser, query/mutation engine, and serializer for CP (clean-room MIT implementation of npm postcss v8).

## 安装与导入

```bash
cap add postcss
```

```cp
import { example } from "postcss";
```
