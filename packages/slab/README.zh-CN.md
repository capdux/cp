# slab

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-heap pre-allocated O(1) slab allocator with intrusive free-list (clean-room port of Rust slab)

## 安装与导入

```bash
cap add slab
```

```cp
import { example } from "slab";
```
