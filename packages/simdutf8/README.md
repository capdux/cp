# `@cap/simdutf8`

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`crates.io:simdutf8` ([https://github.com/rusticstuff/simdutf8](https://github.com/rusticstuff/simdutf8))

Zero-heap strict RFC 3629 UTF-8 validator with 4-byte ASCII fast-path, `basicIsValidUtf8`, `validateUtf8Compat` (`valid_up_to` + `error_len`), `isAscii`, and `countCodepoints` — clean-room CP equivalent of crates.io `simdutf8`.
