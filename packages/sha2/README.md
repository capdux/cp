# `@cap/sha2-crate`

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`crates.io:sha2` ([https://github.com/RustCrypto/hashes](https://github.com/RustCrypto/hashes))（原库名 `sha2` → CP 包名 `@cap/sha2-crate`）

Zero-heap FIPS 180-4 SHA-256 and SHA-224 streaming hashers (`Sha256`, `Sha224`, `sha256Hex`, `sha224Hex`) — clean-room CP equivalent of crates.io `sha2`.

Reuses `@cap/cookie-signature`'s SHA-256 compression core as an independent package.
