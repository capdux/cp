# indexmap

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Pure CP zero-allocation insertion-order-preserving hash map (Rust indexmap v2 parity, reuses @sindresorhus/fnv1a)

## 安装与导入

```bash
cap add indexmap
```

```cp
import { example } from "indexmap";
```
