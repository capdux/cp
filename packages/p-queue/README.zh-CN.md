# p-queue

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-heap priority task queue with concurrency limit, pause/resume, and active/pending tracking (clean-room port of npm p-queue)

## 安装与导入

```bash
cap add p-queue
```

```cp
import { example } from "p-queue";
```
