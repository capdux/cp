# fenwick

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation Binary Indexed Tree (Fenwick Tree) with O(log N) prefix/range sums and binary-lifting lowerBound for CP

## 安装与导入

```bash
cap add fenwick
```

```cp
import { example } from "fenwick";
```
