# bimap

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-heap bidirectional 1-to-1 map (left <-> right) in pure CP, modeled after Rust bimap

## 安装与导入

```bash
cap add bimap
```

```cp
import { example } from "bimap";
```
