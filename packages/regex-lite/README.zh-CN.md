# regex-lite

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation linear-time Thompson NFA regex engine (Rust regex-lite v0.1 parity) composing regex-syntax and memchr

## 安装与导入

```bash
cap add regex-lite
```

```cp
import { example } from "regex-lite";
```
