# bitflags

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`npm:bitfield` ([https://github.com/fb55/bitfield](https://github.com/fb55/bitfield))（原库名 `bitfield` → CP 包名 `bitflags`）

Zero-heap 64-bit bitflags set algebra (`contains`, `intersects`, `unionFlags`, `intersection`, `difference`, `symmetricDifference`, `insert`, `remove`, `toggle`, `countBits`, `lowestBitIndex`, `formatHex`) for CP.
Compatible with Rust `bitflags`.
