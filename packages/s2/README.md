# `s2`

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`crates.io:s2` ([https://github.com/roydbt/s2](https://github.com/roydbt/s2))

Zero-heap Google S2 spherical geometry library: 64-bit `S2CellId` Hilbert hierarchy (`face`, `level`, `parent`, `child`, `rangeMin`/`rangeMax`, `contains`), `LatLng` validation, and `haversineMeters` spherical distance — clean-room CP equivalent of crates.io `s2`.
