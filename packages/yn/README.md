# @cap/yn

Zero-allocation yes/no boolean string parser in pure CP supporting strict mode, lenient typo tolerance, and default fallbacks.

## API

- `yn(input: string): bool?`
- `ynLenient(input: string): bool?`
- `ynDefault(input: string, default_val: bool): bool`
