# chalk

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation terminal string styling library (npm chalk v5 parity) with automatic color level detection & Truecolor/256/16/plain downsampling for CP

## 安装与导入

```bash
cap add chalk
```

```cp
import { example } from "chalk";
```
