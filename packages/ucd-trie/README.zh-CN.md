# ucd-trie

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Pure CP zero-allocation compressed two-level bitmap Trie for O(1) Unicode codepoint membership queries (ucd-trie parity)

## 安装与导入

```bash
cap add ucd-trie
```

```cp
import { example } from "ucd-trie";
```
