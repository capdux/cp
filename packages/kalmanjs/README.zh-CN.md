# kalmanjs

> 版本：`1.0.0` | 许可证：`MIT` | 类型声明：[src/index.d.cp](./src/index.d.cp)

Zero-allocation 1D scalar Kalman filter for sensor denoising, smoothing, and linear state prediction in CP.

## 安装与导入

```bash
cap add kalmanjs
```

```cp
import { example } from "kalmanjs";
```
