# @cap/approx

Clean-room MIT, zero-heap IEEE-754 floating-point approximate equality library for CP — modeled on crates.io #130 `approx` (900M+ downloads).

## API
- Constants: `F64_EPSILON`, `F32_EPSILON`
- `absDiffEqF64`, `absDiffEqF32`
- `relativeEqF64`, `relativeEqF32`
- `ulpsDistanceF64`, `ulpsEqF64`, `ulpsDistanceF32`, `ulpsEqF32`
