# @cap/bitflags-crate

Clean-room MIT, zero-heap Rust `bitflags` v2 style `Flags32` & `Flags64` for CP — modeled on crates.io #12 `bitflags` (1.95B+ downloads).

## API
- `Flags32` (`empty`, `all`, `fromBits`, `fromBitsTruncate`, `fromBitsRetain`, `bits`, `isEmpty`, `isAll`, `count`, `contains`, `intersects`, `containsUnknownBits`, `insert`, `remove`, `toggle`, `set`, `clear`, `truncate`, `unionWith`, `intersection`, `difference`, `symmetricDifference`, `complement`)
- `Flags64` (`empty`, `all`, `fromBits`, `fromBitsTruncate`, `bits`, `isEmpty`, `isAll`, `count`, `contains`, `intersects`, `insert`, `remove`, `toggle`, `clear`, `complement`)
