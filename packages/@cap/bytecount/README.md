# `@cap/bytecount`

<!-- cap-source-attribution -->
> **参考 / 吸收来源**：`crates.io:bytecount` ([https://github.com/llogiq/bytecount](https://github.com/llogiq/bytecount))

Zero-heap fast byte counting (`count`, `countFast`), UTF-8 codepoint counting (`numChars`), `countLines`, `countAsciiWhitespace`, and `countInRange` — clean-room CP equivalent of crates.io `bytecount`.

Reuses `@cap/memchr` as an independent package.
