# `@cap/listr2`

Zero-heap CLI task list runner state machine with `PENDING`/`RUNNING`/`COMPLETED`/`SKIPPED`/`FAILED` transitions, retry budgeting, `exit_on_error` halt control, and ANSI status line rendering — clean-room CP equivalent of npm `listr2`.

Reuses `@cap/picocolors` as an independent package.
