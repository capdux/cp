# CP 标准库：国际化消息目录与语言协商引擎 (`cap:i18n` / `cap.i18n`)

> [!NOTE]
> 本子模块已归并至统一主包 `cap:text`，导入请使用 `import { ... } from "cap:text"`。

## 一、 架构总览

`cap:i18n` 是 CP 语言官方内置的纯原生国际化（i18n）引擎，与 `cap:intl`（数值/字节/时长格式化）形成互补，专为全球化 Web 服务、CLI 工具与多语言 AI Agent 应用打造。全模块零 C 依赖、零 `std.posix`、零 `@import("bun")`，支持 `import { ... } from "cap:text"` 与 `import cap from "cap"; cap.i18n.*` 编译期按需惰性挂载。

### 模块文件结构

| 文件路径 | 谱系注释 | 核心职责 |
| :--- | :--- | :--- |
| `lib/i18n/catalog.cp` | `// Source: cp/lib/i18n/catalog.cp (Locale Negotiator, CLDR Plural Rules & I18n Message Catalog)` | `I18nError`、`PluralCategory`、`I18nParam`、`LocaleNegotiator`、`PluralRules`、`I18nCatalog` |
| `lib/i18n/index.cp` | `// Source: cp/lib/i18n/index.cp (Unified Exports for cap:i18n)` | `cap:i18n` 与 `cap.i18n` 统一公开导出入口 |

## 二、 核心 API 速查

### 1. 错误与核心类型

- **`I18nError`**：`LocaleNotFound`、`KeyNotFound`、`InvalidLocale`、`InvalidJson`、`OutOfMemory`。
- **`PluralCategory`**：`Zero`、`One`、`Two`、`Few`、`Many`、`Other`。
- **`I18nParam`**：`{ key: string, value: string }`。

### 2. BCP 47 规范化与 HTTP 语言协商（`LocaleNegotiator`）

- `normalizeLocale(alloc, tag: string): ([]u8) ! I18nError`：统一大小写与分隔符规范化（如 `zh_cn -> zh-CN`、`en-us -> en-US`、`zh_hans_cn -> zh-Hans-CN`、`es_419 -> es-419`），非法标签返回 `I18nError.InvalidLocale`。
- `fallbackChain(alloc, locale: string): ([][]u8) ! I18nError`：生成层次回退链（如 `"zh-Hans-CN"` -> `["zh-Hans-CN", "zh-Hans", "zh"]`），配合 `freeFallbackChain(alloc, chain)` 释放内存。
- `negotiate(alloc, accept_language_header: string, supported_locales: []const string, default_locale: string): ([]u8) ! I18nError`：按 RFC 4647 解析 HTTP `Accept-Language`（支持 `q` 权重降序、稳定排序、`q=0` 排除、精确匹配、层次前缀回退与通配符 `*` 回退）。

### 3. CLDR 基数复数规则（`PluralRules`）

- `select(locale: string, count: i64): PluralCategory`：
  - 英语/德语等：`n == 1 -> One`，其余 `Other`；
  - 法语/葡萄牙语：`0/1 -> One`，其余 `Other`；
  - 中文/日语/韩语等：恒定 `Other`；
  - 俄语/乌克兰语等东斯拉夫语：精确区分 `One`（1, 21...）、`Few`（2..4, 22..24...）、`Many`（0, 5..20, 25..30...）；
  - 波兰语、捷克语/斯洛伐克语、阿拉伯语（`Zero`/`One`/`Two`/`Few`/`Many`/`Other`）。

### 4. 消息目录、安全插值与 JSON 导入（`I18nCatalog`）

- `I18nCatalog.init(alloc, default_locale: string): I18nCatalog ! I18nError` / `deinit(*_)`
- `add(*_, locale, key, template): !` / `addPlural(*_, locale, key, category, template): !`
- `loadJson(*_, locale, json_str): !`：联动 `cap:json` 批量导入扁平或嵌套 JSON 字典，自动展开为点分键（如 `"auth.login_title"`）。
- `t(alloc, locale, key): ([]u8) ! I18nError`：按语言回退链 -> `default_locale` 查找模板；缺失返回 `I18nError.KeyNotFound`。
- `format(alloc, locale, key, params: []const I18nParam): ([]u8) ! I18nError`：单遍扫描 `{key}` 插值与 `{{` / `}}` 转义，替换值中的 `{other}` 不会被二次展开，未提供参数名的占位符原样保留。
- `tp(alloc, locale, key, count: i64, params: []const I18nParam): ([]u8) ! I18nError`：自动按 `PluralRules.select(locale, count)` 选择复数模板并注入 `{count}` 占位符。

## 三、 使用示例

```typescript
const std = @import("std");
import cap from "cap";
import {
    I18nCatalog,
    I18nParam,
    LocaleNegotiator,
    PluralCategory,
    PluralRules,
} from "cap:text";

pub fn demoI18n()! {
    const alloc = std.heap.page_allocator;

    const best = LocaleNegotiator.negotiate(
        alloc,
        "fr-CH, fr;q=0.9, en;q=0.8",
        ["en-US", "fr", "zh-CN"],
        "en-US",
    )?;
    defer alloc.free(best); // "fr"

    let cat = I18nCatalog.init(alloc, "en")?;
    defer cat.deinit();

    cat.loadJson("en", "{\"auth\": {\"welcome\": \"Hello {name}!\"}}")?;
    cat.addPlural("en", "inbox.items", PluralCategory.One, "{count} message")?;
    cat.addPlural("en", "inbox.items", PluralCategory.Other, "{count} messages")?;

    const greeting = cat.format(alloc, "en-GB", "auth.welcome", [
        I18nParam{ key: "name", value: "Alice" },
    ])?;
    defer alloc.free(greeting); // "Hello Alice!"

    const badge = cap.i18n.PluralRules.select("ru", 21); // PluralCategory.One
    * = badge;
}
```
