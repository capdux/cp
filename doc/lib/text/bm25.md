# `cap:bm25` — Okapi BM25 全文检索与 RRF 混合融合标准库

> [!NOTE]
> 本子模块已归并至统一主包 `cap:text`，导入请使用 `import { ... } from "cap:text"`。

## 1. 概述

`lib/bm25/`（导入协议 `cap:bm25` 与 `cap.bm25`）提供纯 CP 实现的工业级倒排索引全文检索引擎与 RAG 混合检索融合能力，无外部 C 依赖，基于显式 `std.mem.Allocator` 管理内存。

核心能力包括：
- **分词与规范化**：ASCII 小写折叠、标点/空白切分、内置/自定义停用词过滤、最大/最小词元长度限制，以及完整保留 UTF-8/CJK 非空白词元。
- **Okapi BM25 倒排索引**：支持动态增删改文档、精确词频与位置记录（Positions），按标准 Okapi BM25 公式与 Robertson-Sparck Jones 平滑 IDF 计算相关性并输出 Top-K 排序结果。
- **严格邻接短语检索**：基于倒排表 `positions` 列表的二分位置匹配，支持多词元连续短语精确检索。
- **RRF 混合检索融合**：通过 `rrfFuse` 实现无量纲 Reciprocal Rank Fusion（`score = sum(weight / (k + rank))`），便于将 BM25 词法检索结果与向量检索结果融合排序。

## 2. 核心类型

| 类型 | 说明 |
| :--- | :--- |
| `TokenizerConfig` | 分词器配置：`lowercase`、`filter_stopwords`、`min_len`、`max_len`、`custom_stopwords` |
| `Bm25Error` | 错误集合：`InvalidConfig`、`OutOfMemory` |
| `Bm25Config` | BM25 参数配置：`k1`（默认 `1.2`）、`b`（默认 `0.75`）、`tokenizer` |
| `Posting` | 倒排记录：`doc_id: u64`、`tf: u32`、`positions: []u32` |
| `Bm25Hit` | 检索命中结果：`doc_id: u64`、`score: f64`（按 `score` 降序、`doc_id` 升序排列） |
| `Bm25Index` | 倒排索引主结构，维护词项倒排表、文档长度表与文档词项逆向映射 |
| `RankedDoc` | RRF 输入排名项：`doc_id: u64`、`rank: usize` |

## 3. API 速查

| 符号 | 签名概要 | 说明 |
| :--- | :--- | :--- |
| `defaultStopwords` | `(): []const []const u8` | 返回内置英文停用词表 |
| `tokenizeTerms` | `(alloc, text, config): ![][]u8` | 分词并分配词元切片数组 |
| `freeTerms` | `(alloc, terms)` | 释放 `tokenizeTerms` 返回的词元数组 |
| `Bm25Index.init` | `(alloc, config): !Bm25Index` | 初始化倒排索引并校验 `k1 >= 0`、`0 <= b <= 1` |
| `Bm25Index.deinit` | `(*_)` | 释放所有倒排表、位置数组及内部映射 |
| `Bm25Index.addDocument` | `(*_, doc_id, text): !void` | 索引文档（若 `doc_id` 已存在则先删除重建） |
| `Bm25Index.removeDocument` | `(*_, doc_id): bool` | 从索引中移除指定文档并清理空倒排表 |
| `Bm25Index.docCount` | `(): usize` | 返回当前索引文档总数 |
| `Bm25Index.avgDocLen` | `(): f64` | 返回当前语料平均文档长度（词元数） |
| `Bm25Index.search` | `(alloc, query, top_k): ![]Bm25Hit` | 执行 Okapi BM25 全文检索并返回 Top-K 命中 |
| `Bm25Index.searchPhrase` | `(alloc, phrase_terms, top_k): ![]Bm25Hit` | 基于位置信息的严格邻接短语检索 |
| `rrfFuse` | `(alloc, lists, weights, k, top_k): ![]Bm25Hit` | 多路排名结果 RRF 加权融合 |

## 4. 示例

```cp
const std = @import("std");
import { Bm25Config, Bm25Index, RankedDoc, rrfFuse } from "cap:text";

pub fn main(): !void {
    const alloc = std.heap.page_allocator;
    let idx = try Bm25Index.init(alloc, Bm25Config{});
    defer idx.deinit();

    try idx.addDocument(1, "Zig and CP systems programming language");
    try idx.addDocument(2, "CP compiler builds fast native binaries");

    const hits = try idx.search(alloc, "systems programming", 5);
    defer alloc.free(hits);

    const list1 = [_]RankedDoc{ .{ .doc_id = 1, .rank = 1 }, .{ .doc_id = 2, .rank = 2 } };
    const list2 = [_]RankedDoc{ .{ .doc_id = 2, .rank = 1 }, .{ .doc_id = 1, .rank = 3 } };
    const lists = [_][]const RankedDoc{ &list1, &list2 };
    const weights = [_]f64{ 1.0, 1.0 };

    const fused = try rrfFuse(alloc, &lists, &weights, 60.0, 2);
    defer alloc.free(fused);
}
```
