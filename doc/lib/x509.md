# `cap:x509` — 纯 CP X.509 v3 证书解析、SAN 匹配与链校验引擎

> **模块路径**: `lib/x509/`  
> **导入协议**: `import { X509Certificate, X509Error, X509Time, SanEntry, BasicConstraints, parseAsn1Time } from "cap:x509";`  
> **动态挂载**: `import cap from "cap";` -> `cap.x509.*` 编译期按需惰性挂载

---

## 一、 架构概述

`cap:x509` 是纯 CP 实现、零 C 外部依赖（无 `std.posix` / `@import("bun")`）的 RFC 5280 X.509 v1/v2/v3 证书解析与验证引擎，底层复用 `cap:asn1` DER TLV 解码器与 `cap:pem` PEM 文本解析器，所有内存由 `ArenaAllocator` 统一托管：

1. **全字段 DER / PEM 证书解析**：
   - `X509Certificate.parseDer(allocator, der_bytes)` 与 `X509Certificate.parsePem(allocator, pem_text)` 解析版本号（v1/v2/v3，拒绝 v4+ 返回 `UnsupportedVersion`）、序列号、签名算法 OID、Issuer/Subject 原始 DER 字节及 CN、有效期、SPKI 原始 DER 字节、SubjectAltName（DNS 与 IPv4/IPv6）及 BasicConstraints（`is_ca` 与可选 `path_len`）。
   - 解析同时计算整张 DER 证书的 SHA-256 指纹（`fingerprintSha256` / `fingerprintSha256Raw`）。
2. **确定性时间与有效期校验**：
   - `parseAsn1Time(tag, bytes)` 与 `X509Time.parse(tag, bytes)` 完整支持 `UTCTime`（`YYMMDDHHMMSSZ`，按 RFC 5280 50 年界线映射 1950–2049）与 `GeneralizedTime`（`YYYYMMDDHHMMSSZ`），严格校验闰年与月日时分秒范围。
   - `cert.isValidAt(unix_sec)` 通过显式传入时间戳进行闭区间 `[not_before, not_after]` 校验，不依赖系统时钟。
3. **RFC 6125 主机名与 IP SAN 匹配**：
   - `cert.matchesHostname(hostname)` 对 DNS 名称执行大小写不敏感匹配与单级左端通配符匹配（`*.example.com` 仅匹配 `api.example.com`，拒绝 `a.b.example.com` 与裸域 `example.com`）；对 IPv4/IPv6 字面量仅匹配 `SanEntry.IpAddress`。
   - 遵循 RFC 6125 第 6.4.4 节：存在 SAN 时不回退检查 `subject_cn`。
4. **CA 签发链基础校验**：
   - `cert.isIssuedBy(issuer_cert)` 校验 `cert.issuer_raw` 与 `issuer_cert.subject_raw` 字节一致性及 `issuer_cert` 的 BasicConstraints CA 约束。

## 二、 核心 API 速查表 (`lib/x509/x509.cp`)

| 符号 / 方法 | 签名与说明 |
| :--- | :--- |
| `X509Error` | `InvalidDer`, `InvalidPem`, `InvalidCertificate`, `InvalidTimestamp`, `UnsupportedVersion`, `OutOfMemory` |
| `X509Time` | `{ unix_sec: i64, is_generalized: bool }`；方法：`parse(tag, bytes)`、`toUnixSec()` |
| `parseAsn1Time(tag, bytes)` | 解析 ASN.1 `UTCTime` (`0x17`) 或 `GeneralizedTime` (`0x18`) 为 Unix 秒时间戳 |
| `SanEntry` | 枚举联合：`DnsName: []const u8`、`IpAddress: []const u8` |
| `BasicConstraints` | `{ is_ca: bool, path_len: u32? }` |
| `X509Certificate.parseDer(alloc, der)` | 解析 DER 证书并返回拥有独立 Arena 的 `X509Certificate` |
| `X509Certificate.parsePem(alloc, pem)` | 通过 `cap:pem` 提取首个 `"CERTIFICATE"` 块并解析 DER |
| `cert.deinit(alloc)` | 释放证书持有的全部 Arena 内存 |
| `cert.isValidAt(unix_sec)` | 判断 `unix_sec` 是否处于 `[not_before, not_after]` 闭区间 |
| `cert.matchesHostname(hostname)` | 按 RFC 6125 校验 DNS/通配符及 IPv4/IPv6 SAN |
| `cert.isIssuedBy(issuer_cert)` | 校验签发者/主体 DER 一致性与 CA BasicConstraints |
| `cert.fingerprintSha256(alloc)` | 返回 64 字符小写十六进制 SHA-256 指纹 |
| `cert.fingerprintSha256Raw()` | 返回 `[32]u8` 原始 SHA-256 摘要 |

## 三、 使用示例

```typescript
const std = @import("std");
import { X509Certificate } from "cap:x509";

fn inspectCert(alloc: std.mem.Allocator, pem_text: []const u8, now_sec: i64): !void {
    let cert = X509Certificate.parsePem(alloc, pem_text)?;
    defer cert.deinit(alloc);

    if (cert.isValidAt(now_sec) && cert.matchesHostname("api.example.com")) {
        const fp = cert.fingerprintSha256(alloc)?;
        defer alloc.free(fp);
    }
}
```
