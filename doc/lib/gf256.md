# `cap:gf256` — Zero-Allocation Galois Field $GF(2^8)$ Arithmetic, Polynomial & Lagrange Library

Pure CP, zero-heap-allocation finite field library over $GF(2^8)$ supporting arbitrary primitive/irreducible polynomials (including **AES `0x11B`** and **Reed-Solomon / QR / RAID-6 `0x11D`**), constant-time branchless multiplication, erasure-coding slice multiply-accumulate, polynomial arithmetic, Lagrange interpolation (Shamir Secret Sharing), and Gauss-Jordan matrix inversion.

## Constants

- `GF256_POLY_AES = 0x1B` ($x^8 + x^4 + x^3 + x + 1$, generator `0x03`)
- `GF256_POLY_RS = 0x1D` ($x^8 + x^4 + x^3 + x^2 + 1$, generator `0x02`)

## Core Types & Functions

- `gf256MulConstTime(a: u8, b: u8, poly_low8: u8): u8` — Branchless 8-iteration table-free multiplication.
- **`Gf256Field`** (stack-resident 512B exp + 256B log tables):
  - Factories: `Gf256Field.init(poly_low8, generator)`, `Gf256Field.aes()`, `Gf256Field.rs()`
  - Scalar ops: `add`, `sub`, `mul`, `div`, `inv`, `pow`
  - Vector ops: `mulAddSlice(dst: *[]u8, src: []const u8, coeff: u8): bool`, `scaleSlice(dst: *[]u8, coeff: u8)`
  - Polynomials (lowest-degree first `c0 + c1*x + ...`): `polyEval(coeffs, x): u8`, `polyMul(a, b, out: *[]u8): usize?`
  - Interpolation & Linear Algebra: `lagrangeInterpolateAt(xs, ys, x_target): u8?`, `invertMatrix(work: *[]u8, inv_out: *[]u8, n: usize): bool`

## Example

```cp
import { Gf256Field } from "cap:gf256";

fn recoverSecret(): u8? {
    const gf = Gf256Field.rs();
    const xs: [3]u8 = [1, 2, 3];
    const ys: [3]u8 = [
        gf.polyEval(&[0x42, 0x17, 0x99], 1),
        gf.polyEval(&[0x42, 0x17, 0x99], 2),
        gf.polyEval(&[0x42, 0x17, 0x99], 3),
    ];
    return gf.lagrangeInterpolateAt(xs[0..], ys[0..], 0); // returns 0x42
}
```
