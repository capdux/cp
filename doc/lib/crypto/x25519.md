# `cap:x25519` — 纯 CP RFC 7748 X25519 椭圆曲线密钥协商引擎

> [!NOTE]
> 本子模块已归并至统一主包 `cap:crypto`，导入请使用 `import { ... } from "cap:crypto"`。

## 概述

`cap:x25519`（亦支持 `cap.x25519` 动态挂载）基于 RFC 7748 与 Zig 0.17 `std.crypto.dh.X25519` 实现常数时间 Curve25519 Diffie-Hellman 密钥交换，内置全零弱公钥/单位元结果拦截。

## 核心类型与 API

- `X25519Error`: `InvalidKeyLength`、`IdentityElement`、`WeakPublicKey`。
- `KeyPair`: `generate()`、`fromSecret(secret: [32]u8)`、`computeShared(self, peer_public)`。
- `scalarmult(secret_key, public_key) -> X25519Error![32]u8`
- `scalarmultBase(secret_key) -> X25519Error![32]u8`

## 示例

```cp
import { KeyPair } from "cap:crypto";

const alice = KeyPair.generate();
const bob = KeyPair.generate();
const s1 = try alice.computeShared(bob.public_key);
const s2 = try bob.computeShared(alice.public_key);
```
