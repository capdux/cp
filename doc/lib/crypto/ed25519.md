# `cap:ed25519` — RFC 8032 Ed25519 数字签名与密钥对标准库

> [!NOTE]
> 本子模块已归并至统一主包 `cap:crypto`，导入请使用 `import { ... } from "cap:crypto"`。

## 1. 概述

`cap:ed25519`（同时支持 `cap.ed25519` 动态挂载）是基于 Zig 标准库 `std.crypto.sign.Ed25519` 实现的零堆分配、确定性 RFC 8032 Ed25519 椭圆曲线数字签名与密钥对管理库。提供密钥对生成、确定性/随机噪声签名、单条验签、批量验签及十六进制编解码能力。

## 2. 核心类型

| 类型 | 底层布局 | 说明 |
| --- | --- | --- |
| `Ed25519Error` | `error` 集合 | 包含 `InvalidLength`, `InvalidHex`, `InvalidEncoding`, `SignatureVerificationFailed`, `KeyGenerationFailed`, `IdentityElement`, `NonCanonical`, `WeakPublicKey` |
| `PublicKey` | `bytes: [32]u8` | 32 字节 Ed25519 公钥，支持 `fromBytes` / `fromSlice` / `fromHex` / `toBytes` / `toHex` / `verify` |
| `SecretKey` | `bytes: [64]u8` | 64 字节 Ed25519 私钥（32 字节 seed + 32 字节公钥），支持 `fromBytes` / `fromSlice` / `fromHex` / `toBytes` / `seedBytes` / `publicKey` |
| `Signature` | `bytes: [64]u8` | 64 字节 Ed25519 签名，支持 `fromBytes` / `fromSlice` / `fromHex` / `toBytes` / `toHex` / `verify` |
| `KeyPair` | `public_key: PublicKey, secret_key: SecretKey` | 密钥对，支持 `generate` / `fromSeed` / `fromSecretKey` / `sign` / `signRandomized` |

## 3. API 速查

- `KeyPair.generate(): Ed25519Error!KeyPair` — 使用系统 CSPRNG 生成随机 Ed25519 密钥对。
- `KeyPair.fromSeed(seed_bytes: [32]u8): Ed25519Error!KeyPair` — 从 32 字节种子确定性派生密钥对。
- `kp.sign(msg: []const u8): Ed25519Error!Signature` — RFC 8032 确定性签名。
- `kp.signRandomized(msg: []const u8): Ed25519Error!Signature` — 带 32 字节随机噪声的签名（防侧信道）。
- `verify(pub_key: PublicKey, msg: []const u8, sig: Signature): bool` — 验证单条签名是否合法。
- `verifyBatch(pub_keys: []const PublicKey, msgs: []const []const u8, sigs: []const Signature): bool` — 批量验证签名集合，全部合法返回 `true`，任一条失败或长度不匹配返回 `false`。
- `toHex(bytes: []const u8, out: []u8): Ed25519Error![]const u8` — 字节切片编码为小写十六进制字符串。
- `fromHex(hex: []const u8, out: []u8): Ed25519Error![]u8` — 十六进制字符串解码为字节切片。

## 4. 示例

```cp
import { KeyPair, verify, verifyBatch } from "cap:crypto";

const kp = try KeyPair.generate();
const sig = try kp.sign("hello ed25519");
const ok = verify(kp.public_key, "hello ed25519", sig);
```
