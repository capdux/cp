# CP 标准库：AWS S3 云存储客户端与 SigV4 签名引擎手册 (`cap:s3`)

## 一、 架构总览与设计准则

`cap:s3` 是 CP 语言官方内置的高性能对象存储标准库，全量吸收自 Bun 原生 S3 引擎（`/data/dev/bun/src/s3_signing/` 及 `runtime/webcore/s3/`）。模块完全兼容 AWS S3、Cloudflare R2、MinIO、阿里云 OSS 等所有支持 S3 REST API 的云存储服务。

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        CP 用户层应用 (Application)                      │
├───────────────────────────────────┬────────────────────────────────────┤
│       高层客户端 (S3Client)        │    请求与预签名构建器 (Builder)     │
│  stat / download / downloadSlice  │  S3RequestBuilder.buildSignedRequest│
│  upload / delete / presignUrl     │  S3RequestBuilder.buildPresignedUrl │
├───────────────────────────────────┼────────────────────────────────────┤
│   分片上传与列表引擎 (Multipart)   │    四级密钥派生引擎 (SigV4Signer)   │
│  MultiPartUpload / ListObjectsV2  │  AWS4-HMAC-SHA256 / sha256Hex      │
├───────────────────────────────────┴────────────────────────────────────┤
│       凭证与端点路由 (S3Credentials) + 类型系统 (S3Acl / StorageClass)  │
└────────────────────────────────────────────────────────────────────────┘
```

## 二、 AWS Signature V4 (AWS4-HMAC-SHA256) 签名算法流

`SigV4Signer` 与 `S3RequestBuilder` 严格遵循 AWS 官方 Signature Version 4 规范，全程在预分配栈缓冲区内完成，**零堆内存分配**：

```text
[1. 规范化请求 CanonicalRequest]
  HTTPMethod + "\n" +
  CanonicalURI + "\n" +
  CanonicalQueryString + "\n" +
  CanonicalHeaders ("host:...\nx-amz-content-sha256:...\nx-amz-date:...\n") + "\n" +
  SignedHeaders ("host;x-amz-content-sha256;x-amz-date") + "\n" +
  HashedPayload (SHA256Hex(body) 或 "UNSIGNED-PAYLOAD")
         │
         ▼  SHA-256 Hex
[2. 待签字符串 StringToSign]
  "AWS4-HMAC-SHA256\n" +
  AmzDate (ISO8601, 如 "20261119T000000Z") + "\n" +
  CredentialScope ("<yyyymmdd>/<region>/s3/aws4_request") + "\n" +
  SHA256Hex(CanonicalRequest)
         │
         ▼  四级 HMAC-SHA256 密钥派生
[3. 派生签名密钥 SigningKey]
  kSecret  = "AWS4" + SecretAccessKey
  kDate    = HMAC-SHA256(kSecret, DateYYYYMMDD)
  kRegion  = HMAC-SHA256(kDate, Region)
  kService = HMAC-SHA256(kRegion, "s3")
  kSigning = HMAC-SHA256(kService, "aws4_request")
         │
         ▼  最终签名
[4. Signature (64 字节小写 Hex)]
  Signature = HexLower(HMAC-SHA256(kSigning, StringToSign))
```

## 三、 核心组件与完整代码示例

### 1. 凭证管理与报头签名请求 (`S3Credentials` & `S3Client`)

支持 **Virtual-Hosted Style**（`<bucket>.<endpoint>/<key>`，AWS S3 / R2 默认）与 **Path-Style**（`<endpoint>/<bucket>/<key>`，MinIO / 私有云常用）：

```typescript
import {
    S3Credentials,
    S3Client,
    S3Acl,
    S3StorageClass,
    S3SimpleRequestOptions,
} from "cap:s3";

pub fn demoS3SignedRequest(): !void {
    let creds = S3Credentials{
        access_key_id: "AKIAIOSFODNN7EXAMPLE",
        secret_access_key: "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        region: "us-east-1",
        endpoint: "s3.amazonaws.com",
        bucket: "ai-artifacts",
        virtual_hosted_style: true,
    };

    let client = S3Client.init(creds);

    // 1. 构造 PUT 上传请求选项
    let extra = S3SimpleRequestOptions{
        content_type: "application/json",
        acl: S3Acl.Private,
        storage_class: S3StorageClass.IntelligentTiering,
    };
    let put_opts = client.upload("models/config.json", "{\"version\":2}", extra);

    // 2. 生成 AWS SigV4 签名请求（零堆分配）
    let url_buf: [256]u8 = undefined;
    let auth_buf: [512]u8 = undefined;
    let signed = client.signRequest(
        put_opts,
        "20261119",
        "20261119T120000Z",
        &url_buf,
        &auth_buf
    )?;

    // signed.url            => "https://ai-artifacts.s3.amazonaws.com/models/config.json"
    // signed.host           => "ai-artifacts.s3.amazonaws.com"
    // signed.content_sha256 => Payload SHA-256 (64 chars)
    // signed.auth_header    => "AWS4-HMAC-SHA256 Credential=..."
}
```

### 2. 预签名 URL 生成 (`presignUrl` / `buildPresignedUrl`)

无需客户端持有密钥，生成带 `X-Amz-Signature` 与 `X-Amz-Expires` 有效期的临时直链：

```typescript
import { S3Credentials, S3Client } from "cap:s3";

pub fn demoPresign(): !void {
    let creds = S3Credentials{
        access_key_id: "AKIAIOSFODNN7EXAMPLE",
        secret_access_key: "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
        region: "us-east-1",
        endpoint: "s3.amazonaws.com",
        bucket: "examplebucket",
        virtual_hosted_style: true,
    };
    let client = S3Client.init(creds);

    let url_buf: [512]u8 = undefined;
    // 生成有效期 86400 秒 (24 小时) 的 GET 预签名下载链接
    const presigned_url = client.presignUrl(
        "GET",
        "test.txt",
        "20130524",
        "20130524T000000Z",
        86400,
        &url_buf
    )?;
    // presigned_url => "https://examplebucket.s3.amazonaws.com/test.txt?X-Amz-Algorithm=AWS4-HMAC-SHA256&...&X-Amz-Signature=aeeed9bbccd4d02ee5c0109b86d86835f995330da4c265957d157751f604d404"
}
```

### 3. Multipart 分片上传与 ListObjectsV2 解析

```typescript
import {
    S3Client,
    S3Credentials,
    UploadPartResult,
    formatCompleteMultipartUploadXML,
    parseInitiateMultipartUploadResult,
    parseCompleteMultipartUploadResult,
    S3ListObjectsOptions,
    parseS3ListObjectsResult,
} from "cap:s3";
const std = @import("std");

pub fn demoMultipartAndList(): !void {
    let client = S3Client.init(S3Credentials{
        access_key_id: "AKIA...",
        secret_access_key: "SECRET...",
        bucket: "dataset-bucket",
        virtual_hosted_style: true,
    });

    // 1. 初始化分片上传 (?uploads)
    let init_req = client.initiateMultipartUploadRequest("large.tar.zst", null);

    // 2. 解析服务端返回的 UploadId
    const upload_id = parseInitiateMultipartUploadResult(
        "<InitiateMultipartUploadResult><UploadId>up-998877</UploadId></InitiateMultipartUploadResult>"
    ).?;

    // 3. 构造第 1 分片与第 2 分片上传请求
    let q_buf: [256]u8 = undefined;
    let part1_req = client.uploadPartRequest("large.tar.zst", upload_id, 1, "part1_bytes", &q_buf);

    // 4. 组装 CompleteMultipartUpload XML 并完成合并
    let parts: [2]UploadPartResult = [
        UploadPartResult{ number: 1, etag: "\"etag1\"" },
        UploadPartResult{ number: 2, etag: "\"etag2\"" },
    ];
    let xml_buf: [1024]u8 = undefined;
    const xml_len = formatCompleteMultipartUploadXML(parts[0..2], &xml_buf);
    let comp_req = client.completeMultipartUploadRequest(
        "large.tar.zst",
        upload_id,
        xml_buf[0..xml_len],
        &q_buf
    );
}
```

## 四、 与 `Bun.s3` / `S3Client` API 对照表

| 功能分类 | Bun (`Bun.s3` / `S3Client`) | CP 标准库 (`cap:s3`) |
| :--- | :--- | :--- |
| **创建客户端** | `new Bun.S3Client({ accessKeyId, ... })` | `S3Client.init(S3Credentials{ ... })` |
| **HEAD 元信息查询** | `s3.stat(key)` | `client.stat(key)` -> `client.signRequest(...)` |
| **GET 全量下载** | `s3.file(key).bytes()` | `client.download(key)` -> `client.signRequest(...)` |
| **GET 区间切片下载** | `s3.file(key).slice(start, end)` | `client.downloadSlice(key, offset, size, &range_buf)` |
| **PUT 单次上传** | `s3.write(key, data, { type, acl })` | `client.upload(key, body, opts)` |
| **DELETE 删除对象** | `s3.unlink(key)` / `s3.delete(key)` | `client.delete(key)` |
| **预签名 URL 生成** | `s3.presign(key, { expiresIn, method })` | `client.presignUrl(...)` / `client.presignPartUrl(...)` / `buildPresignedUrlWithQuery`（支持 STS `session_token`） |
| **可选请求头签名** | 自动加入 CanonicalHeaders | `buildSignedRequest` 严格字母序签名 `content-disposition` / `content-encoding` / `content-type` / `range` / `x-amz-acl` / `x-amz-request-payer` / `x-amz-security-token` / `x-amz-storage-class` |
| **ListObjectsV2 列表** | `s3.list({ prefix, maxKeys })` | `client.listObjectsRequest(opts, &q_buf)` + `parseS3ListObjectsResult` |
| **Multipart 分片上传** | `s3.file(key).writer({ partSize })` | `initiateMultipartUploadRequest` / `uploadPartRequest` / `presignPartUrl` / `completeMultipartUploadRequest` |

## 收敛扩展子模块（`meta.cp` / `sigv4.cp`）

- **S3 元数据与 URI 校验 (`meta.cp`)**：`S3MetaAcl`（8 种标准 Canned ACL 解析/序列化）、`S3MetaStorageClass`（11 种存储类别与归档层判断）、`isValidBucketName`（AWS Bucket 命名规则校验）、`S3Uri`（`s3://bucket/key` 解析）。
- **纯 CP SigV4 独立签名与预签名引擎 (`sigv4.cp`)**：`S3SignError`, `SigV4Credentials`, `SigV4Header`, `SigV4QueryParam`, `SigV4SignedResult`, `awsUriEncode`, `deriveSigningKey`, `signRequest`, `presignUrl`（零外部依赖，支持 `cap.s3.*` 动态挂载）。
