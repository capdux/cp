# `cap:s7` — Siemens S7comm / TPKT (RFC 1006) / COTP (ISO 8073) 零分配编解码库

> [!NOTE]
> 本子模块已归并至统一主包 `cap:iot`，导入请使用 `import { ... } from "cap:iot"`。

纯 CP、零堆分配（zero-alloc）的 Siemens S7comm 工业 PLC 通信协议栈解析库，覆盖 ISO-on-TCP TPKT（RFC 1006）、COTP（ISO 8073）、S7comm 头部（10B Job/Userdata 与 12B Ack/Ack_Data）及 12 字节 S7-Any 变量地址项迭代解析。

## 核心 API

- **TPKT（RFC 1006）**：`isTpkt(data)`、`parseTpkt(data): TpktFrame?`、`encodeTpkt(payload, out): usize?`。
- **COTP（ISO 8073）**：`parseCotp(data): CotpHeader?`（支持 3B DT Data Transfer 及 CR/CC/DR 连接头）、`encodeCotpDt(payload, eot, tpdu_nr, out): usize?`。
- **S7comm**：`isS7(data)`、`parseS7(data): S7Packet?`（校验 `protocol_id == 0x32`、`rosctr in {1,2,3,7}`、10B/12B 头部及参数/数据区越界）、`parseS7OverTpkt(data): S7Packet?`（一步解封 TPKT -> COTP DT -> S7Packet）。`S7Packet.funcCode()` 提取功能码。
- **S7-Any 变量地址迭代**：`S7AnyItemIter`（`initFromParams`, `init`, `next`, `hasError`）零拷贝解码 12B S7-Any 请求项（`0x12, 0x0A, 0x10`），精确拆分 `transport_size`、`length`、`db_number`、`area`、`byte_addr`（24-bit >> 3）与 `bit_offset`（低 3 位）。

## 示例

```cp
import { parseS7OverTpkt, S7AnyItemIter } from "cap:iot";

fn example(tcp_frame: []const u8) {
    if (pkt := parseS7OverTpkt(tcp_frame)) {
        if (it_init := S7AnyItemIter.initFromParams(pkt.params)) {
            let it = it_init;
            while (true) {
                if (item := it.next()) {
                    * = item.db_number;
                    * = item.byte_addr;
                    * = item.bit_offset;
                } else {
                    break;
                }
            }
        }
    }
}
```
