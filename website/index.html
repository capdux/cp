Real Benchmarks, Same Machine

Measured on Intel Xeon Platinum 8175M · Linux x86_64 (-OReleaseFast) vs Bun 1.3.14 & Node v26.1.0. Reproducible via bench/vs_web_frameworks/ & bench/vs_runtimes/.

Write like TypeScript. Run like C & Rust.

Zero garbage collector pauses. Explicit 3-mode ownership (read-only / * / move) with automatic ~init() RAII.

One Binary. Everything Included.

Inspired by Bun, Cargo, and Zig — zero external build scripts or CMake headaches.

⚡ cap.json 2.0 & Workspaces

Four clean 3-letter dependency keys: dep, dev, bin (C/C++ static), and sys (dynamic). Full workspaces glob & workspace:* support.

🌳 AST On-Demand Tree-Shaking

cpc tracks actually referenced external packages via // @cap-used-pkg:. Unused dependencies add 0 bytes to your final binary.

🚀 Parallel .o Cache (-m)

Content-hashed .cap/obj/*.o cache with multi-core parallel compilation and incremental linking. Add --low for low-memory serial mode.

📦 Dual-Format Pack & Publish

Built-in Zstd + libdeflate. Pack split .tar.zst with cap pack --strip, or publish RFC 1952 .tgz directly to npm / Verdaccio via cap publish.

🤖 AI-First Self-Healing Errors

Every diagnostic provides cause, help, and exact fix suggestion — plus cpc fix, cap fmt, and cap lint.

🔄 One-Click Project Migration

Convert existing TypeScript or Rust codebases into idiomatic native CP projects in one command with cap from -ts and cap from -rs.

🔥 Watch Mode & Dead-Code Lint

Instant incremental hot-reload via cap run --watch paired with AST-level unused symbol & dead-code detection via cap lint --dead.

🌐 559K QPS HTTP & 8.71M/s WS

Zero-GC multi-core TCP HTTP/1.1 (19.3 MB RSS) and RFC 6455 WebSocket broadcast (2.48 MB RSS) — up to 37.9x lower memory than Node.

🛡️ Built-in Batteries

Embedded SQLite 3.54.1, SIMD+LazyDFA Regex, Sans-IO WebRTC (cap:rtc), HTTP/1/2/3, PG/MySQL/Redis, IANA TZ, LEB128, and ELF/COFF/Mach-O/SPIR-V.
