# `cap:s3` — 工业级 S3 客户端引擎与 AWS SigV4 标准库

`cap:s3` 是 CP 语言的高性能 AWS S3 兼容对象存储标准库，全量对标并吸收自 Bun 原生 S3 运行时（`bun/src/runtime/webcore/s3/`）与 SigV4 签名系统（`bun/src/s3_signing/`）。该模块提供了从底层的 AWS4-HMAC-SHA256 签名派生算法、请求规范化（Canonical Request）、ListObjectsV2 极速 XML 提取器，到大文件分片上传（Multipart Upload）、流式分段下载（Range / Content-Range）及高阶门面客户端（`S3Client`）的全套工业级支持。

## 核心特性详解

### 1. 严格对标 AWS SigV4 标准（AWS4-HMAC-SHA256）
- **官方向量测试**：通过 AWS 官方文档的标准测试向量验证；
- **四级派生密匙**：`kSecret -> kDate -> kRegion -> kService -> kSigning`；
- **全栈内存安全**：所有请求 URL、Canonical URI、Host 头及 Authorization 报头均依托调用方提供的持久缓冲区构建，严防栈悬垂指针。

### 2. S3 ListObjectsV2 分页与 XML 流式解析
- 采用零依赖的高速标签扫描引擎，精准解析 S3 XML 响应；
- 支持递归提取 `<Contents>` 列表（Key、LastModified、ETag、Size、StorageClass、Owner）、`<CommonPrefixes>` 目录虚拟分层；
- 完备的查询串构建，支持 `prefix`、`delimiter`、`max-keys`、`continuation-token`、`start-after`、`fetch-owner`、`encoding-type`。

### 3. 大文件分片上传（Multipart Upload）
- 支持初始化分块请求解析（提取 `<UploadId>`）；
- 自动生成符合 S3 协议标准的 `CompleteMultipartUpload` XML 请求体；
- 生成单分块上传查询参数（`?partNumber=X&uploadId=Y&x-id=UploadPart`）及取消/完成查询参数。

### 4. 流式下载与 Range 范围解析
- 规范生成 `bytes=start-end` 及 `bytes=start-` Range 标头；
- 解析服务端返回的 `Content-Range: bytes <start>-<end>/<total>` 标头，支持前导/尾随空格与通配符 `*` 容错；
- 内置 `calculateChunkCount` 支持根据文件总量与块尺寸极速分片规划。

## 代码使用示例

### 1. 初始化客户端与生成 SigV4 签名请求

```typescript
import { S3Credentials, S3Client, S3SimpleRequestOptions } from "cap:s3";

// 1. 初始化凭据
let creds = S3Credentials{
    access_key_id: "AKIAIOSFODNN7EXAMPLE",
    secret_access_key: "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
    region: "us-west-2",
    endpoint: "s3.us-west-2.amazonaws.com",
    bucket: "my-data-bucket",
    virtual_hosted_style: true,
};

// 2. 初始化 S3Client
let client = S3Client.init(creds);

// 3. 构建 GET 下载请求并计算 AWS SigV4 报头
let dl_opts = client.download("documents/report.pdf");

let url_buf: [256]u8 = undefined;
let auth_buf: [512]u8 = undefined;

let signed = client.signRequest(
    dl_opts,
    "20261119",
    "20261119T120000Z",
    url_buf[0..256],
    auth_buf[0..512]
) catch unreachable;

// signed.url         => "https://my-data-bucket.s3.us-west-2.amazonaws.com/documents/report.pdf"
// signed.auth_header => "AWS4-HMAC-SHA256 Credential=AKIAIOSFODNN7EXAMPLE/20261119/us-west-2/s3/aws4_request, SignedHeaders=host;x-amz-content-sha256;x-amz-date, Signature=..."
```

### 2. 对象列表分页查询（ListObjectsV2）

```typescript
import { S3ListObjectsOptions, formatListObjectsQuery, parseS3ListObjectsResult } from "cap:s3";
const std = @import("std");

// 构建查询参数
let q_buf: [256]u8 = undefined;
let opts = S3ListObjectsOptions{
    prefix: "photos/2026/",
    delimiter: "/",
    max_keys: 100,
};
let q_len = formatListObjectsQuery(opts, q_buf[0..256]);
// q_buf[0..q_len] => "list-type=2&prefix=photos/2026/&delimiter=/&max-keys=100"

// 解析 S3 服务端 XML 响应
const xml_response = "<?xml version=\"1.0\" encoding=\"UTF-8\"?>...";
let res = parseS3ListObjectsResult(std.heap.page_allocator, xml_response) catch unreachable;
defer res.deinit(std.heap.page_allocator);

for (item of res.contents) {
    // item.key, item.etag, item.object_size, item.storage_class, item.owner
}
for (dir of res.common_prefixes) {
    // 目录前缀 (子文件夹)
}
```

### 3. 大文件分片上传管理（MultiPart Upload）

```typescript
import {
    parseInitiateMultipartUploadResult,
    UploadPartResult,
    formatCompleteMultipartUploadXML
} from "cap:s3";

// 1. 从 InitiateMultipartUpload 响应解析 UploadId
let upload_id = parseInitiateMultipartUploadResult(xml_init) ?? "";

// 2. 构造完成分块上传请求体 XML
let parts: [2]UploadPartResult = [
    UploadPartResult{ number: 1, etag: "\"etag-part-1\"" },
    UploadPartResult{ number: 2, etag: "\"etag-part-2\"" },
];
let xml_buf: [1024]u8 = undefined;
let len = formatCompleteMultipartUploadXML(parts[0..2], xml_buf[0..1024]);
// 输出: <CompleteMultipartUpload><Part><PartNumber>1</PartNumber><ETag>"etag-part-1"</ETag></Part>...</CompleteMultipartUpload>
```

### 4. HTTP Range 分段流式下载

```typescript
import { formatRangeHeader, parseContentRange, calculateChunkCount } from "cap:s3";

// 格式化 Range 请求头
let r_buf: [64]u8 = undefined;
let r_len = formatRangeHeader(0, 1048576, r_buf[0..64]); // => "bytes=0-1048575"

// 解析 Content-Range 响应头
let range_info = parseContentRange("bytes 0-1048575/10485760");
if (r := range_info) {
    // r.start => 0
    // r.end   => 1048575
    // r.total => 10485760
}

// 自动分片规划
let total_chunks = calculateChunkCount(10485760, 1048576); // => 10 chunks
```
